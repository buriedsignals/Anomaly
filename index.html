Find the record that doesn't fit.

Anomaly tells an investigating agent which data could help its case, how to get it, and which detectors fit that kind of data. Then it runs those detectors on the tables the agent fetched, and every unusual record comes back as a lead you can trace.

An agent asks the questions and code does the counting.

Anomaly sits between an investigating agent, such as Spotlight, and the data. The model chooses what to look at, and deterministic code computes every flag.

  1. 1

    Ask

    A journalist or agent starts with a question about a person, a company or a beat.

  2. 2

    Look up

    anomaly.context lists the data that covers the domain and the detectors that fit it.

  3. 3

    Fetch

    The agent gets the tables itself, following each source's SKILL.md.

  4. 4

    Run

    anomaly.oneshot runs the detector's SQL in a sealed DuckDB. The same tables always give the same result.

  5. 5

    Lead

    Each flagged record comes back as a JSON line with its detector, inputs and parameters.

  6. 6

    Gate

    A person accepts or dismisses each lead. A detector never decides what's true.

Sources and detectors meet at a domain.

A domain is a type of data, such as lobbying or procurement. A source says which domain it covers, and a detector says which domain it reads. When a detector joins several tables, the domain publishes their shape, so any source that fills it works with every detector in that family. No source is ever wired to a detector.

  • It only flags.A lead says a record is unusual for a stated reason. It never claims identity, intent or wrongdoing, and the known false positives travel with every detector.
  • The same tables give the same answer.Detectors are read-only SQL, pinned by an implementation hash, so anyone can rerun a lead and get it back.
  • It sees only what it needs.The runner loads only the mapped or contract columns, then cuts DuckDB off from files and the network before the query runs.
  • Paid and restricted data stays visible.A catalogued source has no adapter but still tells the agent the data exists, what it costs and how a person can get it.

Install it once, then three commands do the work.

Anomaly is a local Python package with no account, server or API key of its own. It needs Python 3.11 or later and uv.

Installgit clone https://github.com/buriedsignals/Anomaly.git && cd Anomaly && uv sync
Look upuv run python -m anomaly.context --domain lobbying
Sourceuv run python -m anomaly.context --source global/opensanctions
Runuv run python -m anomaly.oneshot --table donations.csv --request request.json --approved

Request format, domain detectors and every refusal rule are in docs/catalogue.md. Anomaly also runs a full standalone case, with two journalist gates, replay and an independent reviewer: see the case workflow.
