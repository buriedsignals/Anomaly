# Prove installed searchable anomaly review end to end

## Goal

Verify the complete installed structured and semantic review experience and document only proven behavior.

## Acceptance criteria

- Prove fresh installation with the model accepted and offline local embedding smoke tests.
- Prove fresh installation with the model skipped while structured search and triage remain functional.
- Exercise structured filtering, inspection, flagging, drafting, replay, review, and report generation in a portable case.
- Exercise Gate A consent, hybrid query, triage, invalidation, and replay with text-heavy data.
- Exercise exact symbol or path retrieval and natural-language code retrieval with attributable code units.
- Prove report generation still consumes only Gate-B-accepted findings.
- Document model license, locality, projections-versus-evidence, limitations, rebuild rules, and uninstall behavior.

## Non-goals

- Hosted search.
- Automatic publication.
- Semantic confidence claims.

## Audit

Required: installed artifact identity, no case-data egress, cleanup containment, license notices, and end-to-end evidence boundaries.
