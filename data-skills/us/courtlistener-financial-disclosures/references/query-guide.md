# Judicial disclosure query guide

## Resolve identity first

1. Search the CourtListener judicial-person skill.
2. Resolve aliases and confirm the correct person ID with independent biography.
3. Query disclosures using only that numeric ID.
4. Review report year, amendment status, extraction flag, and source PDF.

## Review extracted rows

For a material investment, gift, debt, or income row, preserve:

- report ID/year and filer person ID;
- description/source exactly as extracted;
- original value code and range, not a fabricated point estimate;
- transaction type/date and `has_inferred_values`;
- redaction flag;
- page/source PDF and retrieval time.

Check the PDF visually. Then corroborate any claimed conflict with docket,
party, recusal, ownership, transaction, and timing evidence. A disclosed asset
alone is not proof of misconduct or a disqualifying conflict.

## No-result language

Say “CourtListener returned no covered disclosure for this person ID/query” —
not “the judge filed no disclosure” or “the judge had no financial interests.”

## Reporting checklist

- Identity resolution and person ID.
- Report year/type/amendment and extraction status.
- Exact range/inference/redaction representation.
- PDF checked and page noted.
- Independent conflict/matter evidence and counterevidence.
- Provider coverage and retrieval date.
